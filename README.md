# Credit_Card_Financial_Dashboard

Project Overview:

An end-to-end data analytics project built to simulate a Credit Card Financial Reporting Dashboard. Developed using Power BI — covering data import from customer and transaction records, data modeling, KPI definition, and interactive dashboard delivery across Customer and Transaction reporting views.


This project reflects the responsibilities of a Banking / Credit Card Data Analyst:

Integration of customer demographic data with credit card account and transaction data
Definition, implementation, and maintenance of KPIs for customer acquisition, revenue, and delinquency tracking
Data modeling and relationship building between customer and credit card tables
Development of two interactive Power BI report pages — Customer Report and Transaction Report
Weekly/quarterly trend analysis to support credit risk and revenue decision-making


Tools & Technologies:

Tool:	Purpose
Power BI:	Data modeling, DAX measures, interactive dashboard
Power Query:	Data cleaning and transformation
GitHub:	Version control and documentation
